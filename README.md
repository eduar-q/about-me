## About Me

I'm **Eduar Q.**, a **Computer Engineer** interested in Linux systems, defensive security, infrastructure and automation.

My technical path started with **hardware, operating systems, troubleshooting and networking**. Over time, that foundation led me toward Linux administration and cybersecurity.

Today I focus on turning technical concepts into small, functional projects.

I use **Python, Bash and native Linux tools** to inspect systems, automate repetitive tasks, review configurations and make technical information easier to understand.

I prefer building tools around a simple question:

> **What problem is actually worth solving?**

Rather than building large frameworks, I usually start with a small idea that can be tested on a real Linux environment and expanded when there is a reason to do so.

## Featured Projects

### [🩺 El Médico Forense](https://github.com/eduar-q/el-medico-forense)

A lightweight Python tool for **initial Linux system triage**.

It checks selected system signals such as disk usage, memory, listening TCP ports and SSH configuration, then produces a readable assessment and structured JSON output.

**Focus:** Linux • Python • System Triage

---

### [🎭 El Camuflaje](https://github.com/eduar-q/el-camuflaje)

A small Python tool for preparing technical information before sharing it publicly.

It preserves useful structure while replacing configured sensitive or internal information such as IP addresses, usernames, hostnames and paths.

**Focus:** Python • OpSec • Information Handling

---

### [🛡️ Cybersecurity Foundations Lab](https://github.com/eduar-q/cybersecurity-foundations-lab)

A read-only Bash toolkit for practicing and documenting fundamental Linux security checks.

It covers areas such as network exposure, users and permissions, processes, services, authentication logs and SSH configuration.

**Focus:** Bash • Linux • Defensive Security

---

### [🔑 Linux Privileged Access Review](https://github.com/eduar-q/linux-privileged-access-review)

A small Python utility for reviewing privileged Linux accounts by correlating group membership with available login activity.

The goal is to help identify accounts that may deserve further administrative review.

**Focus:** Python • Linux Accounts • Access Review
